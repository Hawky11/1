# Stage100 — результат без новой DLL

Оригинальный `AALib.exe` проверен: SHA256 `28cd69a7b6219ff0fa101ecebfcbe98962dc3f391b522d1fd6e32c006cf855ba`.

- `F34D0` на исследованной ветке возвращает прежний `ESI` либо `0x27` (внутри есть вызов `F30B0`).
- `F7A8F` переносит возвращённый `EAX` в `ESI`; существующий Stage96 уже отслеживает эту точку, а Stage95 фиксирует обход на `F7A94`.
- Это **не доказательство**, что в текущем бою случилась замена на `0x27`: без чтения полного одного сеанса Stage96/95/98 подсчёт неизвестен.
- Внешние helper-функции могут иметь игровые побочные эффекты; F34D0/F30B0 не считать чистой арифметикой.
- Проверка по оригинальному EXE 15/15; 8/8 synthetic tests, 120 искусственных join-событий, 270 комбинаций. Нет ни DLL, ни установщика, ни новых хуков.

Архив `ArcanaAI_Stage100_F34D0_ReturnProvenance_StaticAudit.zip` из чата содержит `Stage100_Analysis/tools/stage100_audit.py` и `test_stage100.py`. Не требуется новый запуск, если они сохранены локально.
