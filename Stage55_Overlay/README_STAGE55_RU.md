# Stage55 — три ранние границы изменения координат

Исходники готовы. Проверки оригинального PE и 384 синтетические проверки обёрток пройдены. **MSVC x86 сборка и запуск в игре ещё не выполнены.**

## Установка поверх работающего Stage54 r2

В `D:\INCUBATOR\ArcanaAIOverhaul\src`:

1. Заменить `Stage38CallbackWindow.inl` файлом из `Stage55_Overlay/src` этой ветки.
2. Добавить `Stage55EarlierMotionCoordinate.inl` из той же папки.
3. Сохранить рабочий `Stage54PreParentCoordinate.inl` **r2** и все предыдущие файлы Stage35–53. INI и Build.bat менять не нужно.
4. Запустить `Build.bat`. Только при `BUILD SUCCEEDED` заменить DLL в игре файлом `build\dinput8.dll`.
5. Архивировать прежние логи, запустить обычный COM-vs-COM бой. Дать диагностике записать данные хотя бы 30–60 секунд; перед выходом оставить несколько секунд на сброс буферов.
6. Загрузить `Build.log`, новый `ArcanaAI_Stage55EarlierMotionCoordinateTrace.log` и актуальные Stage47–54 логи из этого же запуска.

## Признаки установки

```text
STAGE55_EARLIER_MOTION_COORD_BUILD=2026-11-10-r1
STAGE55_INSTALLED 3/3 A119B->AE6E0 A11A0->ACDF0 A11A5->AC8A0
```

После начала боя нужны `STAGE55_EARLIER_WINDOW` с обеими сторонами и всеми тремя callRVA; `preMask=1FFF postMask=1FFF`; HEALTH с `missingObjects=0 dropped=0 overflow=0 mismatch=0 badCaller=0`.

Если установка отклонена, не обходить проверку сигнатур: прислать лог с `STAGE55_SIGNATURE_FAILURE` и Build.log.

## Зачем этот этап

Stage54 r2 показал 504 изменения X уже до A2B81. Теперь проверяются:

| Вызов | Роль в диагностике |
|---|---|
| A119B → AE6E0 | Включает первый вызов Stage47 AE70C; отделяет оставшуюся часть родительской функции |
| A11A0 → ACDF0 | Следующая функция; в оригинальном EXE найдены записи в object+7C |
| A11A5 → AC8A0 | Следующая граница после ACDF0 |

`AE93E` — второй вызов Stage47 — находится в другой функции, AE880. Его нельзя автоматически считать вложенным в AE6E0.

Диагностика наблюдает прежние 13 полей P1/P2. Она не задаёт движения, атаки или координаты. Возможное улучшение поведения AI этим этапом не доказано.
