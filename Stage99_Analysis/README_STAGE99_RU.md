# Stage99 — class 5: static-only, без новых хуков

Исходный SHA256 `AALib.exe`: `28cd69a7b6219ff0fa101ecebfcbe98962dc3f391b522d1fd6e32c006cf855ba`. Анализ оригинальных RVA F7A49–F7A97 и helper 525CD0 сделан на 2026-11-12.

**Итог:** class5 всегда идёт в `F7A94` (BYPASS), а не в `F7A99` (F3930 producer). Если `mode3A34 != 2`, вызывается `F34D0`. При mode=2 helper 525CD0 возвращает 0 для кодов 0/1/2/9/10, тогда вызывается F34D0; для остальных кодов возвращает 1, тогда F34D0 пропускается. Аргумент действия F34D0 = `0x22` при bit2 `3B70`, иначе `0`.

В уже проверенном Stage98 r2 все **461** событий class5 имеют mode=0 (208) или mode=1 (253); из оригинального кода следует `F34D0` для всех. Это **статический вывод по ранним логам**, не новый game runtime.
